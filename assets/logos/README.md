# Logos

Official marks, used small and unaltered on title blocks.

- `osdu.svg`: the OSDU® logo from The Open Group's OSDU Forum page (https://www.opengroup.org/osdu-forum/, `sites/default/files/2026-06/OSDU.svg`), downloaded 2026-10-09.
- `microsoft.png`: Microsoft's full-colour logo with grey wordmark (`Microsoft-logo_rgb_c-gray.png` from the official logo pack), cropped to its bounds. Use it on light backgrounds only; never recolour it.
